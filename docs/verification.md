# Game verification

Run `sh scripts/check.sh` with the pinned Godot 4.7.2 runtime. All suites use the current five-day policy campaign.

- Policy content checks cover all 75 packets, eight rules, keyword token boundaries, source line limits, and per-file ink exceptions.
- Simulation and clock checks cover five-minute shifts, twenty-second arrivals, explicit selection, exact citations, consultation unlocks, immutable transitions, payroll, evenings, Friday completion, and invalid action histories.
- Save checks exercise three independent slots, JSON round trips, backup recovery, malformed data, current tutorial progress, and rejection of unsupported formats. There is no compatibility campaign.
- Interface and application checks cover source rendering, compact rule descriptions, read-only Slouch, incoming PR links, notification counts, pause/focus handling, window layout, tutorial arrows, and the cold-open → orientation → morning memo → shift sequence.
- Press checks cover all five daily editions, clickable stories, memo gating, and newly introduced rules without leaking audit answers.
- Desktop-window checks cover dragging, resizing, maximize/restore, clipping, and supported viewport sizes.

Native and single-thread Web exports use the Compatibility renderer. Screenshots under ignored `build/` provide visual checks of the actual native controls. `sh scripts/run.sh --script res://tools/capture.gd -- <dir>` renders the menu, cold open, orientation, morning reader, Slouch, Review, Handbook, a stamped review, and pause to PNGs. Displayed source is never executed. Windows packaging, notarized distribution, audio, and comprehensive screen-reader support remain outside this milestone.
